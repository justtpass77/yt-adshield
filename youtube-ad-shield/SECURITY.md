# Security Policy

## Supported Versions

We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or bypass loophole within AdShield:

1. **Do not create a public issue** on GitHub.
2. Please report it privately by opening a [GitHub Security Advisory](https://github.com) or reaching out directly to the maintainers.
3. Include steps to reproduce the issue, sample URLs (if public), and browser environment details.

We appreciate your responsible disclosure and will acknowledge receipt within 48 hours.
